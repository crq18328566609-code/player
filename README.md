# 飞行棋 · 和机一起玩

八个版本的双人飞行棋，支持人机轮流掷骰、进度保存、可拖动浮窗。

## 规则要点

1. **停下才生效**：只有棋子停在格子上才触发内容；路过不触发。
2. **后进格**：停在「后进X格」上会实际后退 X 格。
3. **格子内容**：停下的人接受该格内容。你停在某格 → 机可按该格内容对你行动；机停在某格 → 你可按内容对机（或机用文字/剧情执行）。
4. **回合**：你的回合自己点「掷骰子」；机的回合对机说「到你了」后触发投掷。

## 给前端 / 机的接口

```js
// 触发机投掷
window.flightChessAiRoll()

// 获取最近一次停下的格子事件（建议注入机提示词，可取2轮）
// 返回 { who, pos, text, roundsLeft } 或 null
window.flightChessGetLastEvent()
```

机投完后，用 `flightChessGetLastEvent()` 把 `text` 注入提示词两轮，让机知道要执行什么。

## 本地进度

使用 `localStorage` key：`flight_chess_player`

## 浮窗

最小化后右下角出现浮窗，可拖动；点「飞行棋进行中」恢复。

## 快速打开

浏览器直接打开 `index.html` 即可。
